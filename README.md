# uru-databases-2-go-api-common

Intended as a Go module of Gin middlewares and helper functions shared by Pixel Plaza API projects. The repository only contains the module definition.

**Note:** This repository is archived and read-only. It holds no Go source files: the last commit says the code was forked into `github.com/ralvarezdev/go-jwt` and `github.com/ralvarezdev/go-gin`. The Pixel Plaza API gateway still imports this module for its Gin auth and header middleware and gRPC client response helpers, so use those versions of the module rather than this branch.
